# Fragrance Launchpad

STUDENT ACTIVITY BRIEF

Build & Launch Your Own Sarkar Perfume Brand

An AI landing page challenge using Lovable, GitHub, PageSpeed Insights and Codex

What This Activity Is About

Sarkar Perfume has a store at sarkar.store. In this activity, you will imagine and launch your own

signature fragrance under the Sarkar Perfume brand. You will keep the existing Sarkar packaging exactly

as it is. Your job is not to redesign the packaging. Your job is to create a landing page that sells your

fragrance idea, then make that landing page fast, clean and mobile friendly using AI tools.

You will use an AI website builder called Lovable to build the page, publish it, test its speed, fix problems,

and if needed, connect it to GitHub and use an AI coding agent called Codex to finish the job. By the end,

you will have a live, published landing page that you built and improved yourself.

Reference store: https://sarkar.store/

Learning Goals

● Understand how a brand extension or flanker product idea is positioned and sold on a landing

page.

● Get hands on experience with an AI website builder (Lovable).

● Learn how to read a website performance report and understand why mobile speed matters.

● Learn the basics of GitHub as a backup and version control tool.

● Get an introduction to AI coding agents (Codex) and how they connect to real repositories.

Step 1: Explore Sarkar Store and Pick Your Fragrance

1. Visit sarkar.store and look at how the brand presents its perfumes, packaging, pricing and tone of

voice.

2. Pick or invent your own fragrance name, notes (for example citrus, oud, floral, woody) and a one line

brand story.

3. Do not change the Sarkar packaging design. Your fragrance should look like it belongs on the same

shelf as the existing Sarkar products.

Doubt to resolve: confirm with your trainer whether the fragrance name needs to be original or can be

inspired by an existing global perfume, since this affects how you write the product description.

Step 2: Build Your Landing Page With Lovable

1. Open Lovable and start a new project for your fragrance landing page.

2. Include at minimum a hero section with the fragrance name and tagline, a section on fragrance notes,

a product image area, pricing or a call to action button, and a footer.

3. Keep the Sarkar packaging visuals intact if you are using product images. Focus your creativity on the

page layout, copywriting and offer, not the packaging.

Watch first: https://www.youtube.com/watch?v=vyrL7oiy1TQ

Step 3: Publish and Test With PageSpeed Insights

1. Publish your landing page from Lovable so it has a live link.

2. Go to pagespeed.web.dev and paste your live link to run the test.

3. Check both the Mobile and Desktop tabs. Most students will find more issues on the Mobile score.

Note down the specific warnings, for example large images, unused code, or slow loading elements.

Watch first: https://www.youtube.com/watch?v=Z4-dcjP39q8

Doubt to resolve: if your Mobile and Desktop scores are both low, still prioritise fixing Mobile issues first,

since most real visitors to a perfume landing page will be browsing on their phone.

Step 4: Fix the Issues Using Lovable

1. Go back into Lovable and describe the specific PageSpeed issue you found, for example asking it to

compress images or remove unused sections.

2. Republish the page and run PageSpeed Insights again to confirm the score has improved.

3. Repeat this fix and test cycle until the Mobile score is in a healthy range, or until Lovable is no longer

able to resolve the issue.

Step 5: Backup Plan, Connect Lovable to GitHub

If Lovable cannot fix the issue directly, do not worry. This is exactly why we back up the project to

GitHub.

1. Create a free GitHub account if you do not already have one.

2. Inside your Lovable project, use the GitHub connection option to link the project and push your code

to a new GitHub repository.

3. Confirm that your repository now shows your Lovable project files.

Create a GitHub account and first repo: https://www.youtube.com/watch?v=b4u04SqBYoM

Connect Lovable to GitHub: https://www.youtube.com/watch?v=9xSVkX2OBcU

Step 6: Level Up, Use Codex to Finish the Fix

1. Download and set up Codex on your system, https://openai.com/codex/ or use the ChatGPT web

version of Codex.

2. Connect Codex to the GitHub account and select the repository you created in Step 5.

3. Describe the exact PageSpeed issue to Codex and ask it to make the fix directly in the code.

4. Once Codex has made the change, sync or redeploy so your published website reflects the update.

Run PageSpeed Insights one more time to confirm.

Codex for beginners: https://www.youtube.com/watch?v=0TitiOk7hbI

## Build with Lovable

Continue developing this project in the [Lovable editor](https://lovable.dev/projects/7808785d-da14-4aa6-ba8e-2288290ecb83).

- **Ship faster**: describe what you want to build and Lovable handles the code.
- **Stay in sync**: every change made in Lovable is committed straight to this repository.
- **Full ownership**: this code is yours. Push to `main` on GitHub and your changes sync back into Lovable, ready for your next prompt.

npm i
